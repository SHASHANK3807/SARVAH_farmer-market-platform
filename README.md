# 🌾 SARVAH — Farmer Market Platform

**SARVAH** is a multilingual digital agricultural marketplace designed to strengthen market linkages and improve price discovery for farmers. The platform provides a centralized interface for farmers and buyers to access agricultural market information and facilitate more transparent connections.

The project was developed as a prototype for **Smart India Hackathon 2026 — Problem Statement 26132: Strengthening market linkages and price discovery for farmers**.

## 🚀 Key Features

- 🌐 **Multilingual Interface** — Designed to make the platform accessible to farmers across different language backgrounds.
- 👨‍🌾 **Farmer-Centric Platform** — Provides farmers with tools and information to participate more effectively in agricultural markets.
- 📊 **Market & Price Discovery** — Presents market-related information to help users compare and understand available price opportunities.
- 🤝 **Farmer–Buyer Linkages** — Facilitates connections between agricultural producers and potential buyers.
- 📱 **Responsive Web Interface** — Designed for accessibility across desktop and mobile devices.
- 🧩 **Modular Architecture** — Organized into reusable application components, data, localization, and supporting modules.

## 🛠️ Technology Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **JavaScript**
- **Node.js / npm**

## 🎯 Objective

The primary objective of SARVAH is to address challenges faced by farmers in accessing reliable market information and reaching suitable buyers. By bringing market information and farmer–buyer interactions into a unified digital platform, the project aims to support more informed selling decisions and improve market accessibility.

## 📌 Problem Statement

Traditional agricultural markets can involve multiple intermediaries and limited access to timely market information, making it difficult for farmers to identify suitable buyers and understand prevailing prices.

SARVAH proposes a digital solution focused on:

- Better access to market information
- Improved price transparency
- Direct farmer–buyer connectivity
- Multilingual accessibility
- A more user-friendly digital agricultural marketplace

## 💻 Running the Project

Clone the repository and install the dependencies:

```bash
git clone https://github.com/SHASHANK3807/SARVAH_farmer-market-platform.git
cd SARVAH_farmer-market-platform
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
